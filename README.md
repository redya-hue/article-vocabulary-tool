# 文章词汇提取工具

从英文文章和论文中提取较高难度单词与专业短语，整理音标、中文释义、原文例句、例句翻译和词性，导出 CSV 词表，方便阅读积累与后续背诵。

适用于英文文献阅读，可提取 `carbon sequestration`、`soil respiration` 等专业短语，并过滤 `he`、`she`、`a`、`the` 等基础词。

**当前版本为 v2.0，支持 API 自动提取、截断后自动拆分和断点继续。**

## 下载与启动

**安装 Python 3.10 或以上版本后，下载并完整解压程序包，双击 `start_windows.bat` 即可启动，无需手动输入命令。**

1. 在本项目右侧的 **Releases** 中打开发布版本，下载 **Assets** 中上传的完整 ZIP 程序包。
2. 将压缩包完整解压到电脑上的任意文件夹。
3. 双击文件夹中的 **`start_windows.bat`**。
4. 在打开的界面中导入文章，选择提取方式，开始使用。

首次使用时，如果电脑尚未安装 Python，请先从 [Python 官网](https://www.python.org/downloads/windows/) 安装 Python 3.10 或以上版本，安装时勾选 **Add Python to PATH**。

请完整保留程序文件及 `data`、`vendor` 等子文件夹，不要单独移动启动文件。PDF 解析库已随包提供，无需额外安装。

也可以在程序目录中运行：

```bash
python article_vocab.py
```

## 主要功能

- 支持粘贴英文正文，或导入 TXT、MD、DOCX、PDF。
- 根据公开词表筛选高阶单词，并结合模型识别专业术语。
- 支持提取由 2—6 个词组成的原文连续专业短语。
- 自动整理音标、中文释义、原文例句、例句翻译及词性。
- 分批处理长文章，遇到输出截断时自动拆分重试。
- 自动保存成功批次，支持中断后继续。
- 支持预览、查看详情、删除词条和导出 CSV。
- 保留“无 API：复制提示词”模式。

## 使用方法

### API 自动提取

1. 启动程序，粘贴文章或点击导入按钮选择文件。
2. 填写研究领域，例如生态学、自然地理、气候变化或森林碳循环。
3. 如需提取专业术语，保持“专业单词与短语”选项开启。
4. 填写 API 地址、模型名称和 API Key，确保所填模型可用。
5. 点击 **“自动提取 / 继续”**，等待处理。
6. 检查结果，双击词条查看详情，删除不需要的条目。
7. 点击 **“导出 CSV + 核验记录”**，保存词表。

程序支持兼容 Chat Completions 的接口。API 地址可以填写根地址或完整的 `/chat/completions` 地址；是否需要 `/v1`，以服务商要求为准。

程序不会将输入的 API Key 写入配置或导出文件。文章正文会发送到所填写的 API 服务商。API 调用费用由服务商收取，自动拆分重试可能增加调用次数。

### 无 API：复制提示词

没有 API Key 时，可以使用手动模式：

1. 输入文章，点击 **“无 API：复制提示词”**。
2. 将提示词粘贴到你使用的 AI 对话工具中，取得完整 JSON 结果。
3. 回到本程序，点击 **“粘贴 AI 返回的 JSON”**。
4. 核验结果并导出 CSV。

该模式下，本程序不发起模型 API 请求；AI 对话工具自身的使用额度与费用规则仍然适用。

每次最多处理 50000 字符，长文请分批输入。修改正文后，应重新复制提示词，确保原文编号一致。

## 搭配 WordMemorizer 背单词助手使用

本工具可以作为 [WordMemorizer 背单词助手](https://github.com/wenki2005/word-memorizer) 的词表整理工具，将论文阅读中遇到的词汇用于后续学习与复习。

使用流程：

1. 使用本工具从英文文章中提取词汇。
2. 检查词条与释义，导出 CSV。
3. 打开 WordMemorizer，在“词库”页面使用导入功能，选择导出的 CSV 文件。
4. 选择对应词库，开始学习，并使用其间隔重复功能安排复习。

WordMemorizer 支持 CSV 导入。本项目尚未完成两者的端到端兼容性测试，建议先导入少量词条，检查音标、释义、例句和翻译是否正确显示。

WordMemorizer 是独立的第三方项目，两者通过词表文件衔接。

## 导出格式

CSV 包含以下六列，不包含 `source` 来源列。

| 列名 | 内容 |
| --- | --- |
| `word` | 单词原形或原文专业短语 |
| `phonetic` | 音标，不确定时或专业短语留空 |
| `meaning` | 原文语境下的中文释义 |
| `example` | 对应的原文句子或片段 |
| `translation` | 原文例句或片段的中文翻译 |
| `pos` | 词性，例如 `n.`、`v.`、`adj.`、`n. phr.` |

CSV 使用 UTF-8 BOM 编码，方便在 Windows Excel 中查看中文。程序按 `word + pos` 去重，同一词、同一词性保留首次提取的例句。

导出时还会生成同名 `.audit.json` 文件，记录筛选依据、过滤原因、完成状态、API 调用统计和仍失败的片段，便于检查处理情况。

## 词汇筛选规则

普通单词采用以下公开词表规则：

```text
（六级词表 ∪ 托福词表 ∪ SAT 词表）
−（初中词表 ∪ 高中词表 ∪ 四级词表 ∪ 基础停用词）
```

这是偏严格的筛选方式，不代表官方难度认证，也可能排除一些值得学习的词。

专业单词由模型结合研究领域判断，但仍优先排除基础词。专业短语按整体概念筛选，允许包含基础词。例如，`soil respiration` 可以作为完整术语保留。

程序会核验词条与原文的对应关系，但模型仍可能漏词或产生不准确的释义、音标、词性及翻译，建议在导入背词软件前检查。

## 长文处理与断点继续

程序没有固定的词条数量上限。长文章会分批处理，每批约 1500 字符，默认输出上限为 8000 token，可在界面调整。

遇到模型输出截断或不完整 JSON 时，程序会在有限次数内拆分当前批次重试。网络、鉴权或余额等错误会暂停处理。

成功批次会自动保存到本机。保持文章、API 地址、模型、领域和提取设置一致，再次点击 **“自动提取 / 继续”**，即可复用已完成部分。调整输出上限仍可复用进度。

请注意：

- 取消复用进度会重新提取，并可能产生新的 API 费用。
- 在预览中删除词条不会修改批次缓存，继续处理时可能恢复这些词条。
- 点击停止后，需要等待当前请求结束。
- 只有全部批次成功才显示“全文处理完成”；部分完成时仍可导出已获得的词条。
- “全文处理完成”表示各批次处理成功，不代表模型一定提取了所有合格词汇。

Windows 进度通常保存在：

```text
%LOCALAPPDATA%/ArticleVocabularyAPI/checkpoints/
```

## 文章导入注意事项

- PDF 需包含可提取文字；扫描版 PDF 请先进行 OCR。
- PDF 分栏、页眉页脚、断行与连字符可能影响正文质量，导入后建议检查。
- 可选择跳过独立 `References` 或 `Bibliography` 标题之后的内容。
- 很长的句子可能拆成片段，此时导出的例句为对应原文片段。
